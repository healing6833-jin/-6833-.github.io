# 훼이맵 장부 웹앱 — 처음부터 설치하기

엑셀 파일을 올릴 필요 없습니다. **빈 구글 시트**에 코드 두 개만 붙여 넣으면, 웹앱을 처음 열 때 장부 시트 9개(장부·입출금일보·부가세집계·월별손익·월간입출금·재고입출고·품목·재고·기초설정·사용안내)가 자동으로 만들어집니다.

## 1. 새 구글 시트 만들기
1. https://sheets.new 에 접속합니다 (장부 주인 구글 계정으로 로그인).
2. 왼쪽 위 제목을 `훼이맵 장부 2026`처럼 바꿉니다.

## 2. 코드 붙여 넣기
1. 그 시트에서 **확장 프로그램 → Apps Script**를 누릅니다.
2. `Code.gs`에 있던 내용을 **모두 지우고**, 이 폴더의 `Code.gs` 내용을 붙여 넣습니다.
3. 왼쪽 **파일 옆 ＋ → HTML** → 이름에 `Index` 입력(확장자 없이) → 이 폴더의 `Index.html` 내용을 붙여 넣습니다.
4. 💾 **저장** (Ctrl+S).

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**.
2. ⚙ **유형 선택 → 웹 앱**.
3. 다음 사용자 인증 정보로 실행: **나** / 액세스 권한이 있는 사용자: **나만**  ← 장부가 남에게 보이지 않도록 꼭 "나만".
4. **배포** → 권한 승인 창: 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)으로 이동 → 허용**. (내가 만든 스크립트라서 나오는 정상 안내입니다.)
5. 나온 **웹 앱 URL**을 엽니다. 첫 실행은 시트를 만드느라 **30초~1분** 걸립니다. 휴대폰에서는 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.

## 4. 처음 한 번 입력
- 시트의 **[기초설정]**: 계좌별 시작 잔액(통장·현금 등)을 넣습니다.
- **[품목·재고]**: 판매 상품·원료·용기를 등록하고 안전재고를 적습니다.
- 웹앱의 **목표 설정**에 이번 달 매출 목표를 넣으면 오일병이 매출만큼 차오릅니다.

## 5. 고객관리 추가하기 (이미 장부 웹앱을 쓰고 있다면 여기부터)
장부 웹앱 안에 고객관리 화면이 들어갑니다. 주소는 그대로이고, 오른쪽 위 **고객관리 →** / **장부로 →** 버튼으로 오갑니다.

1. 장부 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs` 내용을 **모두 지우고** 이 폴더의 새 `Code.gs`를 붙여 넣습니다. (화면 전환과 메뉴가 바뀌었습니다.)
3. `Index`(HTML)도 모두 지우고 이 폴더의 새 `Index.html`을 붙여 넣습니다. (오른쪽 위 고객관리 버튼이 생겼습니다.)
4. **파일 옆 ＋ → 스크립트** → 이름 `Crm` → 이 폴더의 `Crm.gs`를 붙여 넣습니다.
5. **파일 옆 ＋ → HTML** → 이름 `Crm` → 이 폴더의 `Crm.html`을 붙여 넣습니다.
6. 💾 저장 → 위쪽 함수 선택 칸에서 **`setupCrm`** → ▶ **실행**. 권한 승인 창이 다시 뜹니다. 탈리 응답 시트를 읽고 자동 실행을 만드는 권한이 새로 필요해서예요. 3단계 4번처럼 허용하세요.
   - 장부 시트 뒤에 **고객 · 문의 · 고객관리설정** 시트 3개가 생깁니다. 장부 시트는 그대로입니다.
7. **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**. 웹앱 주소는 바뀌지 않습니다.

### 탈리 문의 연결
1. tally.so → **훼이맵 상담 · 예약 신청** 폼 → **Integrations → Google Sheets → Connect** → 장부와 같은 구글 계정을 고릅니다. 탈리가 응답용 구글 시트를 새로 만듭니다.
2. 그 시트를 열고 주소창의 주소(`https://docs.google.com/spreadsheets/d/…`)를 복사합니다.
3. 웹앱 **고객관리 → 설정** 탭에 붙여 넣고 **주소 저장 → 지금 가져오기**를 누릅니다.
4. **자동 가져오기 → 켜기**를 누르면 15분마다 새 문의를 가져옵니다. 웹앱을 열 때도 한 번씩 가져옵니다.

- 같은 문의는 두 번 들어오지 않습니다(탈리의 Submission ID로 구분). 연락처가 같으면 같은 고객으로 묶입니다.
- 이미 있는 고객의 칸은 **비어 있을 때만** 탈리 내용으로 채웁니다. 사장님이 고친 값은 그대로 둡니다.
- 음력 생일 고객은 별자리 대신 **양력 생일 확인 필요**가 뜹니다. 양력으로 바꿔 고객 창의 생일(양력)에 넣으면 별자리·추천 오일이 나옵니다.
- 별자리·추천 오일은 홈페이지 향기카드의 대표 오일과 같습니다. 향기카드 짝을 바꾸면 `Crm.gs`와 `Crm.html` 위쪽의 `ZODIAC` 표도 같이 바꿔 주세요.
- 개인정보는 탈리 동의 문구대로 **상담 종료 후 1년 이내 파기**합니다. 고객관리 홈의 **보관 기간 지남**에서 대상 고객을 확인하고 지울 수 있습니다.

## 6. 영수증 사진으로 입력 켜기
장부 화면의 **영수증 사진으로 입력** 칸에서 **📷 카메라로 찍기**(휴대폰은 카메라가 바로 열림) 또는 **🖼 사진 고르기**를 누르면, Gemini가 영수증을 읽어 아래 입력칸(일자·거래내용·금액·거래처·계정과목·증빙·결제수단)을 채웁니다. 확인한 뒤 **장부에 저장하기**를 누르세요. 사진은 장부에 남지 않습니다.

1. 새 `Code.gs`와 `Index.html`을 붙여 넣고 💾 저장합니다.
2. **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**. 외부 서비스(Gemini)에 연결하는 권한이 새로 필요해서 승인 창이 뜹니다. 3단계 4번처럼 허용하세요.
3. https://aistudio.google.com/apikey 에서 장부 계정으로 **API 키 만들기** → 키를 복사합니다. (무료 등급으로 충분합니다.)
4. 웹앱을 열면 영수증 칸 아래에 키 입력칸이 보입니다. 붙여 넣고 **키 저장**. 한 번만 하면 됩니다.
   - 키는 Apps Script의 **프로젝트 설정 → 스크립트 속성**에 `GEMINI_API_KEY`로 저장됩니다. 키를 바꾸려면 거기서 고치거나 지우세요.

## 코드를 고친 뒤에는
**배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**를 해야 웹앱에 반영됩니다. (저장만 하면 예전 버전이 계속 보입니다.)

## 이런 오류가 나오면
| 화면 문구 | 원인과 해결 |
|---|---|
| `Cannot read properties of null (reading 'getRange')` | 예전 버전 코드입니다. 새 `Code.gs`를 붙여 넣고 **새 버전으로 배포**하세요. |
| `장부 시트 중 일부만 있습니다` | 시트 이름이 겹칩니다. 새 구글 시트(sheets.new)에서 다시 시작하세요. |
| 한참 동안 "불러오는 중"에서 멈춤 | 브라우저에 구글 계정이 여러 개 로그인돼 있으면 생깁니다. 시크릿 창에서 장부 계정 하나로만 열어 보세요. |
| `탈리 응답 시트를 열 수 없습니다` | 주소가 틀렸거나, 탈리 시트가 다른 구글 계정에 있습니다. 장부 계정으로 열리는 시트 주소인지 확인하세요. |
| `Submission ID · 성함 · 연락처 칸을 찾지 못했습니다` | 탈리가 만든 응답 시트가 아닌 다른 시트 주소입니다. 탈리 Integrations에서 만든 시트 주소를 넣으세요. |
| 고객관리 버튼을 눌러도 장부가 보임 | 새 버전으로 배포하지 않았습니다. 5단계 7번을 해 주세요. |
| `이 스크립트는 구글 시트에서 … 만들어야 합니다` | script.google.com에서 따로 만든 프로젝트입니다. 1단계의 구글 시트 안에서 **확장 프로그램 → Apps Script**로 다시 만드세요. |

## 알아 둘 점
- `Index.html`이나 `Crm.html`을 그냥 브라우저로 열면 **데모 데이터**로 화면만 미리 볼 수 있습니다(저장 안 됨).
- 시트 메뉴 **훼이맵 장부**에 **장부 시트 만들기 · 고객관리 시트 만들기 · 탈리 문의 지금 가져오기**가 생깁니다.
- 고객 정보가 든 시트와 웹앱은 꼭 **"나만"** 볼 수 있게 두세요. 고객 시트를 내려받은 파일은 홈페이지 저장소(GitHub)에 올리지 마세요.
- 부가세 숫자는 일반과세자 기준 예상치입니다. 신고 전에 홈택스 자료와 대조하세요.
